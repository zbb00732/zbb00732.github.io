# 地上ユニット（4.7）

## 4.7.1 ユニットの構成

### Ground Element（地上要素）

ユニット内部の個別装備、人員の集まり。以下が含まれる。

- 人員（分隊単位）
- 個別の車両、砲、兵器
- 支援分隊（通信、衛生、兵站など）
- 移動用トラック

### TOE（Table of Equipment）

そのユニットが本来持つべき Ground Element の種類と数の定義（定員）。

Unit Detail 画面のTOE表示例:

```plaintext
TOE: 15 / 20
→ 即応要素が定数の 15%
→ 損傷中も含めると 20%
```

Support Squadは この数値に含まれない。

## 4.7.2 ユニット種別

| 種別 | 概要                                     | ZOC       |
| ---- | ---------------------------------------- | --------- |
| CU   | 主力戦闘ユニット<br />ブレークダウン可能 | あり      |
| HQ   | 指揮統制担当<br />戦闘不可               | なし      |
| SU   | HQ または CU に配属して支援              | なし      |
| MRU  | CU と SU の両方として運用可能            | CU 時あり |

### SU（Support Unit）の配属ルール

#### CU に直接配属できる SU（確実に戦闘参加）

- 対戦車
- 対空
- 装甲
- 突撃砲
- 工兵
- スキー
- 戦車
- 駆逐戦車

#### HQ にのみ配属できる SU（確率的にコミット）

- 砲兵
- 榴弾砲
- 迫撃砲
- ロケット砲

#### HQ にのみ配属できる SU（非戦闘）

- 建設
- 労働（要塞地帯は例外）

#### CU への直接配属数の上限

| CU 種別      | 上限 |
| ------------ | ---- |
| 枢軸歩兵     | 3    |
| 装甲師団     | 3    |
| ソ連軍団     | 3    |
| ソ連狙撃師団 | 1    |

#### HQ 配属のSUコミット範囲

| 参加の種類       | 必要距離                       |
| ---------------- | ------------------------------ |
| 攻撃支援         | 戦闘ヘクスから 3 ヘクス以内    |
| 防御支援         | 戦闘ヘクスから 6 ヘクス以内    |
| 都市、Urban 戦闘 | 2 ヘクス以内なら MP 制限を免除 |

## 4.7.3 ビルドアップ、ブレークダウン、マージ

ホットキー: `b`

### ブレークダウン（分解）

| 元部隊 | 分解結果 |
|---|---|---|
| ドイツ師団 | 3 個連隊相当 CU に分解（青ボーダーで表示） |
| ソ連戦車 | 3 個旅団に分解 |
| ソ連機械化軍団 | 3 個旅団に分解 |
| ソ連狙撃軍団 | 3 個師団に分解 |
| ソ連騎兵軍団 | 3 個師団に分解 |
| ソ連山岳軍団 | 3 個師団に分解 |

### ビルドアップ（統合）

| 元部隊 | 等号結果 |
|---|---|---|
| ソ連狙撃旅団 2 個 | ソ連狙撃師団 1 個 |
| ソ連空挺旅団 3 個 | ソ連親衛狙撃師団 1 個（1942年3月以降） |

### マージ（合併）

- コスト: 1 AP
- 条件: 同種別、同等以下サイズのユニット
- 吸収されたユニットは永久にゲームから削除

### 共通の制約

- 壊走中、凍結中は不可
- ブレークダウンはスタック制限を超えられない
- ビルドアップ、マージは移動モードにある必要がある

## 4.7.4 HQ とリーダーシップ

### 指揮官の 7 つの能力値

| 能力値     | 主な影響                                             |
| ---------- | ---------------------------------------------------- |
| Political  | 更迭コスト<br />解任 / 粛清確率                      |
| Morale     | 戦闘 CV<br />疲労増減<br />壊走ユニット回復          |
| Initiative | MP<br />射撃精度<br />Reserve / SU コミット判定      |
| Admin      | MP<br />機体 / Ground Element 修理<br />補給消費判定 |
| Mech       | 自動車化ユニットの CV<br />射撃精度                  |
| Infantry   | 非自動車化ユニットの CV<br />射撃精度                |
| Air        | 航空任務への参加機数                                 |

### 指揮判定の仕組み（連鎖判定）

```plaintext
能力値 / 10 = 通過確率（例: Admin 6 → 60%）
↓ 失敗した場合のみ上位 HQ へエスカレーション
↓ ただし距離ペナルティにより通過確率は低下
```

判定失敗分のみ上位 HQ へ引き継がれるため、下位指揮官の質が最も直接的に影響する。上位指揮官は補完的な存在。

### HQ の指揮範囲（Command Range）

| HQ種別                              | 指揮範囲  |
| ----------------------------------- | --------- |
| High Command（Stavka / OKH）        | 90 ヘクス |
| Army Group / Front                  | 45 ヘクス |
| Army（枢軸のみ）                    | 15 ヘクス |
| Corps（枢軸） / Army、Corps（ソ連） | 5 ヘクス  |
| Air Command                         | 90 ヘクス |

HQ の支援には 2 種類ある。

Support Squad（支援分隊）の提供は HQ の種別ごとの指揮範囲全体（Corps およびソ連 Army は 5 ヘクス、枢軸 Army は 15 ヘクス、Army Group は 45 ヘクス）をカバーする。

リーダー判定への影響は 5 ヘクス以内はペナルティなし、それを超えると距離に応じて段階的にペナルティが増加し、指揮範囲外になると両方とも完全にゼロになる。

### 指揮容量（Command Capacity）

| HQ 種別                | 容量（1941 / 42 / 43 / 44 年〜） |
| ---------------------- | -------------------------------- |
| Corps（Type 4）        | 9 CP / 9 CP / 10 CP / 11 CP      |
| Axis Army（Type 3）    | 27 CP / 27 CP / 30 CP / 33 CP    |
| Soviet Front（Type 2） | 72 CP / 81 CP / 90 CP / 99 CP    |

| ユニット規模 | CP コスト |
| ------------ | --------- |
| 大隊         | 1         |
| 連隊         | 1         |
| 旅団         | 1         |
| 師団         | 2         |
| 軍団         | 4         |

CP を超過すると指揮判定の通過確率が低下する。

## 4.7.5 ユニット間の関係表示

ユニットを選択すると他のユニットの枠色が変化:

| 色  | 意味                                 |
| --- | ------------------------------------ |
| 紫  | 選択中のユニット                     |
| 橙  | 直属上位 HQ                          |
| 黄  | 同じ HQ に直属する他ユニット（兄弟） |
| 青  | 選択 HQ の配下で指揮範囲内           |
| 赤  | 選択 HQ の配下で指揮範囲外           |

実践的な使い方: HQ を選択して赤表示の CU を確認する。赤の CU は HQ の支援を受けられない。

## 4.7.6 移動モード

| ホットキー | モード          | 用途                 |
| ---------- | --------------- | -------------------- |
| `F1`       | Move Mode       | 通常の戦術移動、戦闘 |
| `F2`       | Rail Mode       | 鉄道輸送（SMP 消費） |
| `F3`       | Naval Transport | 海上輸送             |
| `F4`       | Amphibious      | 水陸両用上陸         |
| `F9`       | Air Transport   | 航空輸送             |
| `F11`      | Battle Locator  | 戦闘サイト表示       |

### 基本操作

- 左クリックでユニット選択
- ダブルクリック or スペースバーでスタック内全ユニット選択
- Shift + 左クリックで複数選択
- 目的地クリックでゲームが自動経路計算
- アンドゥ: `u` キー（敵ヘクス進入後、ZOC 侵入後は不可）

## 4.7.7 ユニット情報の 3 段階

### レベル 1 : カウンター（マップ上）

| カウンター右下三角形 | 状態               |
| -------------------- | ------------------ |
| 白三角 + 内側黒三角  | 未移動             |
| 白三角のみ           | 移動済み残 MP あり |
| なし                 | MP 完全消費        |

| カウンター左上三角形は Soft Factorタブ（色分け）によって情報が変化する。

### レベル 2 : Unit Bar（右クリックまたは選択時）

CU 固有の主要情報:

- Unit Mode（Ready / Refit / Reserve / Static）
- SMP（～ 200 と表示。未使用分は CPP 回復に寄与）
- CPrep（CPP、交差剣マークの後に 0 〜 100 で表示）
- 兵力（兵員数、砲数、戦車数）
- 補給状態（補給、燃料、弾薬の%）

### レベル 3 : Unit Detail Window（ユニット名クリック）

- Ground Element ごとの TOE 充足率
- 配属 SU の一覧
- 全 Soft Factor の詳細数値

## 4.7.8 ユニットモード（詳細）

### プレイヤーが選択するモード

| モード                                                                                                                                                                     | 概要                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| READY (NORMAL)                                                                                                                                                             | デフォルト<br />移動、攻撃、防御すべて通常                                                                                                                                                                                                       |
| REFIT                                                                                                                                                                      | 補充優先<br />防御、移動へのペナルティなし<br />前線に置いたまま Refit も可能だが、デポ上のほうが補充効率が大幅に高い<br />デポ上の Refit ユニットは TOE 100% を目標に補充を試みる<br />HQ も Refit に設定可能（Living Manualエラッタ v1.02.32） |
| RESERVE                                                                                                                                                                    | 予備<br />隣接戦闘への自動コミット<br />攻撃支援: 3 ヘクス以内<br />防御支援: 6 ヘクス以内<br />敵に隣接していてはコミット不可                                                                                                                   |
| STATIC                                                                                                                                                                     |
| 移動力大幅低下（MP = 2）<br />AP とトラックを獲得<br />設定したターンは解除不可<br />解除（Mobilize）するには近隣デポに十分な Freight が必要<br />解除したターンは攻撃不可 |

### 非自発的な状態

| 状態              | 条件                       | 主な制約                                           |
| ----------------- | -------------------------- | -------------------------------------------------- |
| ROUTED（壊走）    | 壊滅的損害                 | ZOC 消失<br />移動不可<br />戦闘不可<br />補充不可 |
| DEPLETED（枯渇）  | 即応要素が TOE の 10% 以下 | ZOC 消失<br />AutoDisplace 発生                    |
| UNREADY（非即応） | 士気 + TOE < 90            | 移動後の攻撃不可                                   |
| ISOLATED（孤立）  | 補給線遮断                 | 補充不可<br />毎ターン士気損失リスク               |
