# ゲーム概要（4.1 ～ 4.3）

## 第 4 章の目的と構成（4.1 〜 4.2）

第 4 章は WITE2 の入門章であり、「まず動かしながら学ぶ」ことを意図した構成です。

| パート                    | 概要                                             |
| ------------------------- | ------------------------------------------------ |
| 第 1 パート（4.3）        | ゲームの最低限の基本概念                         |
| 第 2 パート（4.4〜4.18）  | 各サブシステムの解説                             |
| 第 3 パート（4.19〜4.23） | 「ヴェリーキエ・ルーキ」シナリオのウォークスルー |

## 4.3.1 ゲームの基本定義

- テーマ: 1941 年 6 月 〜 1945 年 8 月の東部戦線
- マップ単位: 1 ヘクス ＝ 10 マイル ＝ 約 16 km
- ターン単位: 1 ターン ＝ 1 週間
- 進行方式: IGO-UGO（一方が全行動を終えてから相手がプレイ）

## 4.3.2 主要ゲーム概念

### Combat Value（CV）戦闘値

- ユニットの総合的な戦闘力の数値
- 2:1の目安: 攻撃側 CV が防御側の 2 倍以上なら防御側は後退、崩壊する可能性が高い
- 地形、補給、リーダー、サポートユニット（SU）などで大きく変動する
- 精密計算より「大まかな優位」を意識する

### Combat Preparation Points（CPP）戦闘準備ポイント

- 0 〜 100% で変動
- 高いほど攻撃 CV が上昇し SU コミット率も上がる
- 攻撃すると残 CPP の半分を失う（最重要）
- 移動するたびに消費
- 休養、未移動、Assault HQ 傘下で回復

### Administrative Points（AP）管理ポイント

- 指揮官交代、デポ建設、ユニット編成などに消費
- 毎ターン一定量を受け取り、未使用分は繰り越し可（上限 9,999）

### ユニット種別

| 種別                    | 概要                                                |
| ----------------------- | --------------------------------------------------- |
| Combat Unit（CU）       | マップ上で戦闘を行う主力<br>ZOC を持つ              |
| Headquarters Unit（HQ） | 指揮統制を担う<br />戦闘不可                        |
| Support Unit（SU）      | HQ または CU に配属して支援を提供する               |
| Multi-Role Unit（MRU）  | CU と SU の両方として運用可能<br />（主にソ連旅団） |

## 4.3.3 ターンの進行順序

1. 兵站フェーズ（コンピュータ自動）
2. 航空計画フェーズ（プレイヤー操作）
3. 航空実行フェーズ（コンピュータ自動）
4. 地上フェーズ（プレイヤー操作）

重要: ソ連先攻シナリオの第1ターンは兵站フェーズがスキップされ、航空計画フェーズから開始する。

## 4.3.5 ユニットモードの変更

| モード                      | 概要                                            |
| --------------------------- | ----------------------------------------------- |
| Ready または Normal（通常） | デフォルト状態                                  |
| Refit（整備）               | 補充を優先的に受け取る<br />防御ペナルティなし  |
| Reserve（予備）             | 隣接戦闘に自動コミット可能                      |
| Static（静置）              | 移動力が大幅低下<br />AP とトラックを獲得できる |

## 4.3.6 マップの構成

| 構成要素                     | 概要                                                   |
| ---------------------------- | ------------------------------------------------------ |
| 地形タイプ                   | 平地、森林、荒地、山岳、沼地、都市など                 |
| 河川                         | ヘクスサイドに沿って走り移動を阻害                     |
| Theatre Box（戦域ボックス）  | マップ外の戦域を抽象化した場所（北アフリカ、極東など） |
| National Reserve（国家予備） | 新ユニットの訓練、損耗ユニットの再建に使用             |

## 4.3.7 マップ表示のトグル

主な表示項目（オン、オフ可能）:

- 道路網（悪天候時の移動計画に特に重要）
- 要塞レベル
- デポネットワーク
- 修復された鉄道線

## 4.3.9 航空ユニットの階層構造

```plaintext
Air Command（航空司令部）
  └── AOG: Air Operational Group（航空作戦群）
           └── Air Group（航空群）← 実際の機体を保有する最小単位
```

- Air Command は Front（ソ連）または Army Group（枢軸）に直接配属される
- AOG はマップ上に「ラベル」として表示（カウンターではない）
- Air Group はマップに表示されず、Air Base Unit に配備

## 4.3.10 地上ユニットの構成

Ground Element（地上要素）とはユニット内部の個別装備、人員の集まり。TOE で定義された定数（定員）に対して現在の充足率で状態を管理する。

### TOE（Table of Equipment: 装備表）の 3 層構造

| TOE 種別       | 内容                                         |
| -------------- | -------------------------------------------- |
| Generic TOE    | 「中戦車が n 両必要」という抽象的な定義      |
| Prescribed TOE | 具体的な機種、モデルまで特定した規定定数     |
| Current TOE    | 現在実際に保有している Ground Element の状態 |

TOE はゲーム進行とともに史実スケジュールで自動更新される（例：Pz.III → Pz.IV）。代替装備使用中の要素は「*」表示。

## 4.3.11 補給（Supply）の基本

Freight（物資）とはすべての補給品を統一する概念。鉄道、船、トラック、馬車で輸送される。

### 物資フローの方向（一方通行）

```plaintext
National Supply Source（Level 4）
  └──鉄道、船 → デポ（Level 1 〜 3）
                    └──トラック → HQ、CU
```

### デポの優先度（プレイヤーが設定する 0 〜 4 の値）

- 数字が高いほど優先的に Freight を受け取る
- 高優先度のデポから低優先度のデポへは送れない
- 後方から前線に向かって段階的に優先度を上げるのが基本

### 補給状態

- In Supply（補給状態）
    - デポへの経路が確保されている
- Isolated（孤立状態）
    - 補給網から遮断
    - 補充不可

## 4.3.12 AP（管理ポイント）の主な使途

| 用途                                   | コスト                           |
| -------------------------------------- | -------------------------------- |
| デポ建設                               | 1 AP                             |
| 指揮官交代                             | 可変（階級、Political 値に依存） |
| Assault HQ 設定                        | 枢軸は 10 AP、ソ連は 20 AP       |
| 要塞ユニット建設（ソ連）               | 2 AP（上限50）                   |
| 要塞ユニット建設（枢軸、1942年末まで） | 4 AP（上限20）                   |

## 設計思想のまとめ

WITE2 は「複雑な計算はコンピュータに任せ、プレイヤーは作戦レベルの判断に集中する」ゲームである。

- CV の精密計算より「 2:1 の優位があるか」という大局的な判断が重要
- CPP、補給、HQ の指揮範囲の 3 点は例外として意識的な管理が必要
- 補給は「高優先度＝保証」ではなく「順番を決めるだけ」であり、総量が不足すれば全員が不足する
