# 移動と戦闘（4.8）

## 4.8 移動の基本

### 移動ポイントの種類

| 略語 | 正式名称                  | 概要                                                           |
| ---- | ------------------------- | -------------------------------------------------------------- |
| MP   | Movement Points           | 戦術移動に消費<br />カウンターに表示                           |
| SMP  | Strategic Movement Points | 鉄道、海上輸送に消費<br />毎ターン 200 付与<br />～ 200 と表示 |

MP と SMP は比例して連動する。一方を消費すると他方も比例して減少。未使用 SMP は CPP 回復に寄与。

### 最大移動力

| ユニット種別              | 最大 MP                  |
| ------------------------- | ------------------------ |
| 非自動車化 CU（騎兵以外） | 16                       |
| 騎兵 CU                   | 22                       |
| HQ ユニット               | 50（ソ連は時期制限あり） |
| 自動車化 CU               | 50（ソ連は時期制限あり） |
| Static                    | 2                        |

最小移動力: 自動車化は燃料切れでも最低 1 MP。非自動車化は補給切れでも最低 8 MP。

### 管理移動（Administrative Movement）

ターン開始時点で友軍支配かつ敵阻止なしのヘクスでは通常より大幅に安いコストで移動できる。疲労蓄積も少ない。

阻止（Interdiction）が 1 以上のヘクスでは管理移動が無効化される。

## 4.8.2 戦闘の種類

### Hasty Attack（拙速攻撃）: 右クリック

- 1 つのスタックからのみ攻撃可能
- 攻撃側 CV が半分になる（重要）
- MP コスト: 自動車化 3 MP + 進入コスト、非自動車化 2 MP + 進入コスト
- Reserve、SU のコミット確率が低下

### Deliberate Attack（決定的攻撃）: Shift + 右クリック

- 複数ヘクスからユニットを集めて攻撃可能
- MP コスト: 自動車化 16 MP + 進入コスト、非自動車化 6 MP + 進入コスト
- Reserve、SU のコミット確率が上昇
- 2 ヘクス後方からの砲兵 CU も参加可能

### 複数ヘクスからの協調攻撃（Deliberate Attackのみ）

1. Shift キーを押しながら参加ヘクスをマウスオーバー→全ユニットが自動選択
2. 不要なユニットを Unit Bar で除外
3. Shift + 右クリックで実行

重要: 攻撃後に前進する MP が残るか確認する。「攻撃参加部隊を突破口前進に使えない」問題を避けるため、一部ユニットを攻撃から外して温存する。

## 4.8.3 戦闘に影響するその他の要因

### 探知レベル（DL: Detection Level 0〜10）

- DL が低い敵への攻撃は奇襲リスクがあり攻撃 CV が低下
- FOW オン時は敵 CV がぼかされる

### 戦闘準備ポイント（CPP: Combat Preparation Points）

- 高いほど CV 上昇、SU コミット率上昇
- 攻撃すると残 CPP の半分を失う
- 移動するたびに消費
- 休養、Assault HQ 傘下で最大回復

### 疲労（Fatigue）

- Ground Element の CV が疲労レベルの 1 / 3 だけ減少
- 移動力（MP）も低下
- 士気、補給状態が高いほど蓄積が遅い

### Reserve Mode（予備モード）

- 攻撃支援: 3 ヘクス以内（Hasty Attack へはコミットしない）
- 防御支援: 6 ヘクス以内

### Assault HQ（突撃司令部）

- AP 消費（枢軸 10 AP、ソ連 20 AP）で設定
- 配下ユニットの CPP 回復速度を最大化

## 4.8.4〜4.8.5 戦闘結果の種類

### 基本判定

| 最終 CV 比 | 結果                                |
| ---------- | ----------------------------------- |
| 2:1 未満   | 防御側がヘクスを保持（攻撃失敗）    |
| 2:1 以上   | 防御側が後退を強制                  |
| 5:1 以上   | 防御側が 2 ヘクス以上後退する可能性 |

### 追加結果

降伏（Surrender）
: ターン開始時に孤立状態だった防御側が、後退経路なしで後退を強制された場合

壊走（Rout）
: 孤立していないが後退経路がない場合、または最終 CV 比がユニットの士気値を超えた場合のリスク

崩壊（Shatter）
: 士気、経験、指揮の組み合わせが悪い場合、後退の代わりに消滅する可能性

偵察戦闘への転換（Hasty Attack 時のみ）
: 攻撃が失敗に終わる場合、優秀な指揮官がいれば損害が軽減される可能性

### 後退損耗（Retreat Attrition）

| 状況                       | 損害倍率 |
| -------------------------- | -------- |
| 通常後退                   | 標準     |
| 未凍結の小河川を越えて後退 | * 2      |
| 未凍結の大河川を越えて後退 | * 3      |

### Combat Delay（戦闘遅延）

攻撃が発生したヘクスには遅延ポイントが付加され、そのターン中の通過コストが増加する。Living Manual v1.04.00 から Combat Delay Effects オプション（STANDARD / REDUCED / MINIMAL）で調整可能。

## 士気の仕組み

国家士気（NM: National Morale）
: ユニット士気の上限
: ユニット士気は NM を超えて回復しない

回復条件（毎兵站フェーズ）
: NM 未満なら最大 NM の 10% まで回復可能（1 ターンあたり）
: 補給良好、10 ヘクス以上敵から離れているなど条件で追加回復

低下条件
: 後退で -1、壊走でさらに -1
: 孤立状態では毎ターン損失リスク
: 補給が必要量の 10% 未満→ -2 のリスク

要点: 「条件の解消＝損失の停止」だが、「回復」には別の条件と時間が必要。NM の水準に向かって徐々に収束する。
