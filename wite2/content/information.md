# 情報アクセス（4.4）

## 4.4.1 操作の基本原則

画面上部のタブ、ボタンは以下の 5 種類の動作のいずれかに基づく。

- クリックでアクション実行
- クリックでマップ上に情報を表示
- クリックで詳細画面を開く
- クリックで数値を変更
- クリックでドロップダウンを表示

ほぼすべての情報はタブ、ホットキー、右クリックのいずれからでもアクセスできる。

## 4.4.2 画面の主要エリア

### Mode Toolbars（モードツールバー）

- 上段
    - Map Information、Info Screens、Administration の 3 タブで切り替わる
- 下段
    - 現在のフェーズ（航空計画、地上）によって内容が変わる

### General Information Box（一般情報ボックス）

画面右上に常駐。以下が常時表示される。

- 現在の日付、ターン番号
- 選択ヘクスの都市名（クリックで都市情報画面へ）
- 利用可能な AP 残数
- 選択ヘクスのデポ、飛行場情報

### Soft Factors Tab（ソフトファクタータブ）

ユニットカウンター左上隅に色分けタブを表示させてユニット状態を把握する。一般に明緑は最良を、赤は最悪を表す。

| Soft Factor             | 赤    | 橙       | 黄       | 暗緑     | 明緑  |
| ----------------------- | ----- | -------- | -------- | -------- | ----- |
| 士気                    | < 41% | 41 - 55% | 56 - 70% | 71 - 85% | 85% < |
| 補給                    | < 41% | 41 - 55% | 56 - 70% | 71 - 85% | 85% < |
| 燃料                    | < 41% | 41 - 55% | 56 - 70% | 71 - 85% | 85% < |
| 弾薬                    | < 41% | 41 - 55% | 56 - 70% | 71 - 85% | 85% < |
| 戦闘準備ポイント（CPP） | < 25% | 25 - 49% | 50 - 74% | 75 - 99% | 100%  |
| 疲労度                  | 100%  | 99 - 75% | 74 - 50% | 49 - 25% | 25% > |
| 補給優先度              | 0     | 1        | 2        | 3        | 4     |

## 4.4.3 マップ表示の切り替え

### ズームレベル（5段階）

| レベル      | 表示内容                                   |
| ----------- | ------------------------------------------ |
| 1（最拡大） | ユニット詳細情報<br />Soft Factors も表示  |
| 2           | ユニット詳細情報。Soft Factors も表示      |
| 3           | ユニット種別のみ                           |
| 4           | ユニット種別と規模                         |
| 5（最縮小） | 国籍、SS / Guards 識別のみ<br />鉄道非表示 |

### 地形カテゴリ

| カテゴリ   | 概要                                                     |
| ---------- | -------------------------------------------------------- |
| 地理的地形 | 各ヘクスの地形タイプ、河川（ヘクスサイド）               |
| 天候       | ホットキー W で表示切替<br />地上天候と航空天候は独立    |
| 人工施設   | 港、飛行場、鉄道は常時表示<br />道路、工場、要塞はトグル |

### 都市地形の防御修正（Living Manual エラッタ v1.02.47）

元マニュアルの表示値と実際の計算が異なる点に注意。

| 地形        | 孤立なし           | 孤立    |
| ----------- | ------------------ | ------- |
| Light Urban | CV * 4 倍 + 修正値 | +3 のみ |
| Heavy Urban | CV * 4 倍 + 修正値 | +4 のみ |

孤立していない守備隊は実質的に CV が 4 倍になるため、都市戦闘は過小評価してはいけない。

### ヘクスコントロール（支配状態）

| 状態             | 意味                                         |
| ---------------- | -------------------------------------------- |
| Friendly         | 友軍支配（ターン開始時から）                 |
| Pending Friendly | 今ターン奪取済み<br />補給、移動に追加コスト |
| Enemy            | 敵支配                                       |

ZOC（Zone of Control）:
すべての CU が隣接 6 ヘクスに発揮する。師団、軍団規模は無占領の隣接ヘクスも変換可能（敵 ZOC がなければ）。

## 4.4.4 戦闘情報の表示

### 戦闘解決レベル（0〜7）

数字キーで変更。デフォルトはレベル1。

| レベル | 内容                                |
| ------ | ----------------------------------- |
| 0      | 自動処理、表示なし                  |
| 1      | 戦闘情報が短時間表示（デフォルト）  |
| 2以上  | 航空戦闘結果の表示が追加            |
| 5〜7   | Ground Element 単位の詳細交戦を表示 |

### CV プレディクター（戦闘前確認）

攻撃ユニットを選択した状態で敵ユニットにマウスを乗せると表示される。

```plaintext
例：
Attacker CV: 45.1
Defender CV: 23.2
```

- 地形、要塞、天候、Hasty / Deliberate の区別を反映した調整済みCV
- リーダーボーナスは含まない
- FOW オン時は敵CVがぼかされる

Living Manual エラッタ（v1.02.47）:

- 攻撃側への地形密集修正が反映されるようになった
- 河川越えや初期冬季天候による即時混乱はプレディクターに反映されない点に注意

## ホットキー一覧（情報アクセス関連）

| キー        | 機能                                                             |
| ----------- | ---------------------------------------------------------------- |
| `w`         | 天候表示のオン、オフ                                             |
| `n`         | デポと鉄道使用量の表示                                           |
| `8`         | Freight フロー表示（赤 = デポ→ユニット、白 = デポ間、青 = 海上） |
| `v`         | VP 画面                                                          |
| `Shift + v` | 勝利地点フラグ表示                                               |
| `Shift + e` | 兵站フェーズイベントログ                                         |
| `Shift + m` | メトリクス画面（グラフ）                                         |
| `Ctrl + s`  | ターンサマリー                                                   |
| `F11`       | 戦闘表示モード（全戦闘、地上、航空）                             |
